# Kangnam data shape

## Canonical shape

```js
{
  members:    [{ id, name, role }],
  projects:   [{ id, code, name, description, status, priority,
                 budget, leaderId, start, end, progress }],
  tasks:      [{ id, code, title, description, projectId, assigneeId,
                 status, priority, start, due, tags:[] }],
  activities: [{ id, text, time }]
}
```

## Invariants — break = silent UI bugs

1. **IDs**: prefixed strings (`m1..`, `p1..`, `t1..`, `a1..`). Generated by `id()` at `js/app.js:5` as `<prefix><base36 timestamp+rand>`. Never numeric.
2. **Codes**: `DA001`, `CV001` 3-digit zero-padded. Auto-incremented by `code()` at `js/app.js:6`. Manual edits must preserve format.
3. **Status enums** (display label in `labels` at `js/app.js:2`):
   - project: `planning | doing | review | done`
   - task:    `todo | doing | review | done`
4. **Priority**: `low | medium | high` (same for project and task).
5. **Dates**: ISO `YYYY-MM-DD` strings (no timezone, no time). `T00:00:00` is appended for comparisons — see `overdue()` at `js/app.js:14`.
6. **Foreign keys**:
   - `task.projectId` → `projects[].id`
   - `task.assigneeId` → `members[].id`
   - `project.leaderId` → `members[].id`
   - Dangling refs render as "Chưa chọn" via `mname()` / `pname()` helpers.
7. **Numeric**: `budget`, `progress` are numbers, not strings. `progress` ∈ [0, 100].
8. **Tags**: array of strings, lowercase preferred.
9. **Activities**: `time` is ISO 8601 datetime (`new Date().toISOString()`).

## Storage contract

- Browser persistence disabled in `js/storage.js`. The whole `data` object is JSON.stringify'd and pushed to Google Sheet cell `B2` via `pushCloud()` debounced.
- Apps Script `doPost` in `apps-script/Code.gs:43-62` overwrites `B2` wholesale — no merge logic. Concurrent edits = last writer wins.

## When you change the shape

1. Update seed in `js/seed.js`.
2. Update every `render` function referencing the field.
3. Add safe defaults — old cloud state lacks the new field. Use `t.foo ?? defaultValue`.
4. NO migration step exists; cloud state will be silently rewritten on next save with the new shape.

## Validation checklist before commit

- [ ] All `task.projectId` exist in `projects[].id`
- [ ] All `task.assigneeId` / `project.leaderId` exist in `members[].id`
- [ ] No status or priority values outside the enum
- [ ] No NaN / undefined / null in numeric fields
- [ ] All dates parse with `new Date(d + 'T00:00:00')`
